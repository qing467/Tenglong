# PRD · 个人专属浏览器起始页插件

> 暂定名：**NanoTab（轻起始页）** —— 名字随时可改，改一处即可全局生效
> 版本：v1.0（第一版）　日期：2026-11-01

---

## 一、产品定位

| 项 | 内容 |
| --- | --- |
| **是什么** | 一个替换浏览器新标签页的个人起始页插件 |
| **给谁用** | 本人（单用户自用），不面向公众 |
| **解决什么** | 新标签页默认空白/广告太多；常用网站要翻书签；随手记的东西没地方放 |
| **核心差异（vs 云端壳方案）** | **纯本地实现，不依赖任何服务器，断网可用，数据不出本机** |

### 与云端壳方案的关键区别（本项目的立身之本）

| 维度 | 云端网页 + 扩展壳 | NanoTab（本项目） |
| --- | --- | --- |
| 业务实现 | 云端网页 + iframe 壳 | **纯本地代码，无 iframe、无网络请求** |
| 断网 | 白屏 | **完全可用** |
| 数据位置 | 云端账号 | **`chrome.storage.local`，不出本机** |
| 隐私 | 数据经第三方服务器 | **零上传、零遥测** |
| 体积 | 25 MB | 目标 < 1.5 MB |
| 成本 | 需维护服务器 | **0 元** |

## 三、需求分档

### P0 —— 必须有（第一版上线范围）

#### P0-1 新标签页替换（两态设计）
把浏览器新标签页替换为我们的起始页。**默认只显示壁纸 + 搜索框**（静默态），交互后才展开功能（展开态）。

- **验收标准**
  1. 新建标签页，显示的不再是浏览器默认页，而是 NanoTab 起始页。
  2. 地址栏显示 `chrome://newtab`（保持 iframe-free 的原生体验）。
  3. Chrome 与 Edge 均生效。
  4. 页面无滚动条、无白边，全屏铺满。
  5. **静默态画面只有三样东西**：全屏壁纸、**时钟**、一个空胶囊「搜索」（无底部语句、无便笺、无图标墙）。

#### P0-2 搜索框 + 多引擎切换 + 历史记录
静默态是一个空胶囊；进入搜索态后变成可输入的白色搜索框。

- **验收标准**
  1. 静默态搜索框为**居中胶囊，只有「搜索」两个字**（不是输入框，不聚焦）。
  2. **按回车**或**鼠标点击搜索框** → 进入搜索态，输入框获得焦点。
  3. 搜索态左侧显示**当前引擎图标**，点击弹出引擎列表：**百度 / 必应 / 谷歌 / Yandex / 搜狗 / 360**，每项右侧标注 `Alt+1~6` 快捷键。
  4. 引擎列表底部有**「搜索引擎偏好」**入口（进入搜索引擎管理：可添加自定义引擎、排序、删除）。
  5. 输入关键词回车 → 在当前标签页打开搜索结果页；输入像网址的内容（如 `github.com`）→ 直达该网站。
  6. **历史记录**：记录搜索过的关键词，搜索态下拉显示最近记录；输入时按关键词过滤；底部「清除历史记录」可一键清空。
  7. 记住上次使用的引擎与历史记录，刷新后仍在。

#### P0-3 捷径坞（图标墙）
**默认不显示**；只在"右键空白区域"进入捷径坞时出现。

- **验收标准**
  0. 静默态/搜索态都不显示；**仅在空白处点鼠标右键**进入（左键无效，见 P0-8），Esc 收起。
  1. **列数随窗口自适应**（`auto-fill 76px`）：1088 宽时 9 列、1920 时 12 列、窗口拖窄自动减列，**不溢出不错位**。
  2. 图标为**手机 App 图标风格**：76×76、圆角 19、品牌色底 + 图标充满卡片（不是"白壳套小图标"），名称在卡片下方。
  2. 默认提供若干常用站点（带"示例"标识，可一键清空）。
  3. 可**新增**（末尾虚线「＋」卡片）、**编辑**、**删除**。
  4. 图标**自动抓取 favicon**（`https://{域名}/favicon.ico`；失败降级为站点名首字，且失败不影响页面）。
  5. 支持**拖拽排序**，顺序刷新后保持。
  6. 点击在新标签页打开。
  7. **右键某个图标 → 直接打开「编辑网站捷径」弹窗**（网址 / 标题 / 图标 / 收纳夹 / 保存 / 删除），不再弹右键菜单。
  7.1 点「＋」卡片 → 打开「添加网站捷径」弹窗（同表单，无删除按钮）。
  7.2 弹窗支持：× 关闭、点遮罩关闭、Esc 关闭；网址为空时红字提示且不关闭。
  8. 新增/编辑时有**表单校验**（网址为空或格式错 → 页面内红字提示，不用 alert）。

#### P0-3b 时钟
静默态与各状态顶部始终显示大号时间。

- **验收标准**
  1. 显示 `HH:MM:SS`，每秒自动更新。
  2. 字体极细（200 字重）、大号、居中，距顶约 13vh。
  3. 数字等宽（`tabular-nums`），秒数跳动时**不左右抖动**。
  4. 任何壁纸下都清晰可读（文字阴影 + 顶部暗角）。

#### P0-4 壁纸与遮罩
- **验收标准**
  1. 支持 3 种壁纸来源：**内置渐变（4 套，默认）**、**粘贴图片 URL**、**本地上传图片**（压缩后转 base64 存本地）。
  2. **深色遮罩**开关：开启后背景加深，文字对比度提升；静默态浅、捷径坞态自动加深。
  3. 界面元素为**毛玻璃/半透明白**，背景图上文字不糊（含顶部与底部暗角）。
  4. 壁纸与遮罩设置在刷新后保持。
  5. 背景图自动 `cover` 铺满，不拉伸变形。

#### ~~P0-5 便笺 / 待办~~ ❌ 已移除（2026-11-01）
**不做**：主界面不出现便笺、待办、底部语句，保持「壁纸 + 时钟 + 搜索」的绝对干净。
> 第一版曾规划为"可选面板"，经确认取消；相关 UI、存储字段、设置项一并删除。

#### P0-6 数据持久化与备份（贯穿 P0-2~P0-5）
- **验收标准**
  1. 所有数据存 `chrome.storage.local`，**刷新、关浏览器、重启电脑后都不丢**。
  2. 设置页提供 **「导出备份」**：下载一个 `.json` 文件，包含全部捷径 / 搜索引擎 / 设置。
  3. 提供 **「导入备份」**：选择该 `.json` 文件后完整恢复（导入前提示会覆盖现有数据）。
  4. 提供 **「恢复默认」** 按钮（需二次确认）。
  5. **断网状态下**（拔网线/飞行模式）全部功能仍正常可用。

#### P0-7 扩展弹窗（点击图标）
- **验收标准**
  1. 点击扩展图标弹出 350×600 的面板。
  2. 内含：打开设置页、导出备份、导入备份、版本信息。
  3. 全部使用**页面内提示**，不使用 `alert/confirm`（popup 里 confirm 可能失效）。

#### P0-8 三态交互（静默 / 搜索 / 捷径坞）★核心
打开新标签页默认静默；不同操作进入不同状态，互不干扰。

- **状态定义**
  - **① 静默态（默认）**：壁纸 + **时钟** + 一个空胶囊「搜索」。画面上**没有**图标墙、没有便笺、没有底部语句。
  - **② 搜索态**：时钟 + 白底搜索框（左引擎图标 / 中间输入 / 右绿放大镜）+ 历史记录下拉。
  - **③ 捷径坞**：时钟 + 5 列图标墙（**搜索框消失**）+ 右上角（账号、设置）两个图标。

- **进入 / 退出规则（严格按此实现）**

| 操作 | 静默态 | 搜索态 | 捷径坞 |
| --- | --- | --- | --- |
| 按 **回车** | → 搜索态 | 提交搜索 | — |
| 按**其他任意键** | **无反应** | 正常输入 | — |
| **鼠标左键点搜索框** | → 搜索态 | — | — |
| **鼠标左键点其他区域** | **无反应** | → 静默 | → 静默 |
| **鼠标右键空白区域** | → 捷径坞 | → 捷径坞 | — |
| **右键某个图标** | — | — | 打开「编辑网站捷径」弹窗 |
| **拖动图标** | — | — | 排序（松手即保存） |
| 按 **Esc** | — | → 静默 | → 静默 |

- **验收标准**
  1. 打开新标签页：只在壁纸中央看到走字的**时钟** + 一个「搜索」胶囊，画面干净。
  2. 按 `a` 或空格或方向键 → **什么都不会发生**（不展开、不输入）。
  3. 按**回车** → 进入搜索态并聚焦输入框；点搜索框同样进入。
  4. 搜索态左侧引擎图标 → 弹出 6 个引擎（Alt+1~6 可切换）+ 底部「搜索引擎偏好」入口。
  5. 有历史记录时，输入关键词能实时过滤；「清除历史记录」生效。
  6. 在空白处**右键** → 进入捷径坞（5×3 图标），左键点空白无效。
  7. 捷径坞内**右键图标** → 打开编辑弹窗；**拖动图标**可排序；点「＋」可添加。
  7.1 设置面板打开后，点空白 / Esc / 再点齿轮 都能关闭（不得出现关不掉的情况）。
  8. Esc 或点空白 → 回到静默态，画面再次干净。
  9. 全程无滚动条、无跳动；时钟每秒更新且数字不左右抖动。
  10. 捷径坞内点击**卡片之间的空隙**也要能退回静默态（不能出现"点哪都退不出"）。
  11. 拖动图标排序时，其余卡片平滑让位（FLIP 190ms），不闪动。

## 四、明确不做的事（划清边界，防止范围蔓延）

| 不做 | 原因 |
| --- | --- |
| ❌ 任何服务器 / 后端 / 数据库 | 违背"纯本地"定位，增加成本与维护 |

| ❌ Firefox 适配 | 已确认只做 Chrome + Edge |
| ❌ 移动端支持 | Chrome Android 不支持自定义新标签页 |

## 五、数据模型（初版）

```ts
// 全部存放在 chrome.storage.local，单一 key: "nanotab_data_v1"
interface AppData {
  version: number;            // 数据结构版本，便于日后迁移
  settings: {
    searchEngine: string;     // "baidu" | "bing" | "google"
    theme: "light" | "dark";
    wallpaper: {
      type: "preset" | "url" | "local";
      value: string;          // preset 名 / 图片 URL / base64 dataURL
    };
    showNotes: boolean;
    gridColumns: number;
  };
  shortcuts: Array<{
    id: string;
    name: string;
    url: string;
    iconUrl?: string;
    order: number;
  }>;
  todos: Array<{
    id: string;
    text: string;
    done: boolean;
    createdAt: number;
  }>;
  notes: string;              // 便笺正文
}
```

**存储容量注意**：`chrome.storage.local` 默认上限 10 MB（可申请 `unlimitedStorage`）。
本地上传壁纸转 base64 会较大（一张 1920×1080 约 1-3 MB），因此：
- 上传时**压缩到最长边 1920px、JPEG 质量 0.85** 再存；
- 超过 4 MB 时提示用户改用图片 URL。

## 六、风险与应对（提前说清，不踩坑）

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| **清浏览器数据会丢全部内容** | 高（SOP 踩坑录第 7 条同类） | ① 设置页顶部常驻"导出备份"提醒；② 首次使用弹引导；③ 数据变更时定期提示备份 |
| **换电脑 / 重装浏览器** | 数据只在本机 | 靠导出 JSON 手动迁移（已明确接受） |
| **favicon 抓取失败** | 图标空白 | 降级显示站点名首字，失败不影响其他功能 |
| **本机没装 Node.js** | 卡在阶段 4 | 我会在阶段 4 帮你安装 Node.js LTS |
| **壁纸 base64 撑爆存储** | 写入失败 | 上传时压缩 + 超限提示 |
| **MV3 Service Worker 会休眠** | 后台逻辑失效 | 本项目后台逻辑极简（或无），规避该问题 |

## 七、验收方式（你怎么确认做完了）

1. `chrome://extensions` → 开「开发者模式」→「加载已解压的扩展」→ 选中 `dist/` 目录。
2. 新建标签页 → 看到起始页，直接打字能搜索。
3. 加两个捷径、写一条便笺、换一张壁纸 → 关掉浏览器 → 重开 → 内容都还在。
4. 拔掉网线 → 所有功能仍正常。
5. 导出 JSON → 清空数据 → 导入 JSON → 数据完整恢复。
