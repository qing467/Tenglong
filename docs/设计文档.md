## 二、数据模型（`src/types.ts`）

单一存储 key：`nanotab_data_v1`（整体读写，简单且够用）。

```ts
export type Theme = 'light' | 'dark';
export type EngineId = 'baidu' | 'bing' | 'google';
export type WallpaperType = 'preset' | 'url' | 'local';

export interface Wallpaper {
  type: WallpaperType;
  value: string;                 // preset 名 / 图片 URL / base64 dataURL
}

export interface Settings {
  searchEngine: EngineId;
  theme: Theme;
  wallpaper: Wallpaper;
  showNotes: boolean;
  gridColumns: number;           // 默认 6
}

export interface Shortcut {
  id: string;                    // crypto.randomUUID()
  name: string;
  url: string;                   // 必须带协议
  order: number;
}

export interface Todo {
  id: string;
  text: string;
  done: boolean;
  createdAt: number;
}

export interface AppData {
  version: number;               // = 1，便于日后迁移
  settings: Settings;
  shortcuts: Shortcut[];
  todos: Todo[];
  notes: string;                 // 便笺正文
}
```

**默认值**（首次安装写入，捷径带「示例」标识，可在设置里一键清空）：

```
shortcuts: GitHub / Bilibili / 知乎 / 豆瓣 / MDN / StackOverflow
settings: { searchEngine:'baidu', theme:'light', wallpaper:{type:'preset',value:'aurora'}, showNotes:true, gridColumns:6 }
```

### 存储层约定（`src/lib/storage.ts`）

- `load(): Promise<AppData>` —— 读取，缺失字段用默认值补齐（防止旧数据缺字段崩掉）
- `save(data: AppData)` —— 整体写入，捕获 `chrome.runtime.lastError`
- `reset()` —— 恢复默认（需二次确认）
- 变更通过 `chrome.storage.onChanged` 广播 → `useAppData` 自动更新 UI（保证多标签页同步）

| # | 页面/入口 | 对应需求 | 关键元素 |
| --- | --- | --- | --- |
| 1 | **新标签页** `newtab.html` | P0-1~P0-5 | 壁纸背景 + 毛玻璃卡片层；中央搜索框+引擎选择器；下方捷径九宫格；右下便笺/待办面板；右上角设置齿轮 |

> 说明：设置不做成独立页面，而是 newtab 内的滑出层 + popup 双重入口，减少文件与 manifest 配置。

## 四、关键流程

### 4.1 搜索

```
输入 → 判定是否为网址（含 . 且无空格，或 http(s):// 开头）
  ├─ 是网址 → 补全 https:// → 当前标签打开
  └─ 否则   → 拼 engines[current].url + encodeURIComponent(关键词) → 当前标签打开
```
引擎表（`src/lib/engines.ts`，扩展只需加一行）：

```ts
export const ENGINES = {
  baidu:  { name: '百度',   url: 'https://www.baidu.com/s?wd=' },
  bing:   { name: '必应',   url: 'https://www.bing.com/search?q=' },
  google: { name: '谷歌',   url: 'https://www.google.com/search?q=' },
};
```

### 4.2 捷径增删改与排序

- 新增/编辑：弹出 `ShortcutEditor`，校验 URL（非空 + 自动补 `https://`）→ 失败显示**内联红字**。
- 删除：`ConfirmButton`（第一次点变「确认删除?」，再点才执行）—— 不用 `confirm()`。
- 排序：原生 `draggable` + `onDragStart/onDragOver/onDrop`，按 `order` 重排后整体保存。

### 4.3 便笺与待办自动保存

输入停止 **500ms**（防抖）→ 写入 storage；页面顶部显示「已保存」微提示。

### 4.4 备份导出/导入

- 导出：`Blob` → `URL.createObjectURL` → `<a download="nanotab-backup-YYYYMMDD.json">` 触发下载。
- 导入：`<input type="file">` → `JSON.parse` → **校验 version 字段** → 二次确认「将覆盖现有数据」→ 写入。
- 任一环节失败 → Toast 红字提示（不用 alert）。

## 五、实现顺序（阶段 5 逐模块验收）

| 序号 | 模块 | 产出（可点开验证） |
| --- | --- | --- |
| M1 | 脚手架 + manifest + 空白新标签页 | 打开新标签页看到 "Hello NanoTab" |
| M2 | 数据层（types/storage/useAppData） | 控制台能读到默认数据 |
| M3 | 搜索框 + 引擎切换 | 能搜索、能切引擎、能记住 |
| M4 | 捷径墙 CRUD + favicon + 拖拽排序 | 能增删改、能拖动、刷新保持 |
| M5 | 便笺 / 待办 | 能记、能勾选、刷新还在 |
| M6 | 壁纸与明暗主题 | 能换壁纸、切主题、刷新保持 |
| M7 | 设置面板 + 导出/导入/恢复默认 | 能导出 JSON、导入恢复 |
| M8 | 扩展弹窗 popup | 点图标出面板、功能可用 |

> 每完成一个模块 → 你自己点一遍 → 通过才 `git commit` 拍快照 → 进下一个。

## 六、manifest.json 草案

```json
{
  "manifest_version": 3,
  "name": "NanoTab 轻起始页",
  "version": "1.0.0",
  "description": "一个纯本地、断网可用的极简浏览器起始页。",
  "icons": { "16": "icons/icon-16.png", "32": "icons/icon-32.png", "48": "icons/icon-48.png", "128": "icons/icon-128.png" },
  "chrome_url_overrides": { "newtab": "newtab.html" },
  "action": { "default_popup": "popup.html", "default_icon": { "16": "icons/icon-16.png", "32": "icons/icon-32.png" } },
  "background": { "service_worker": "background.js", "type": "module" },
  "permissions": ["storage"],
  "minimum_chrome_version": "100"
}
```

注意：`background.js` 需与 Vite 输出的 `[name].js` 一致（已关闭 hash）。
