# UI 设计规范 v4 · NanoTab 轻起始页

> 修订：2026-11-01（第四版）
> 变化：**去掉底部语句**、**去掉便笺/待办**；捷径坞改为**列数随窗口自适应**；图标改为**手机 App 图标风格**（图标充满卡片，不再是小图标套白壳）
> 配套预览：`ui-preview/index.html`

---

## 一、核心逻辑：三态

| 状态 | 画面内容 | 进入 | 退出 |
| --- | --- | --- | --- |
| **① 静默态**（默认） | 壁纸 + **时钟** + 一个空胶囊「搜索」 | 打开新标签页 | — |
| **② 搜索态** | 时钟 + 白底搜索框（引擎图标 / 输入 / 绿色放大镜）+ 历史下拉 | **回车** 或 **左键点搜索框** | Esc / 点空白 |
| **③ 捷径坞** | 时钟 + 自适应图标墙（**无搜索框**）+ 右上角两个图标 | **右键空白区域** | Esc / 点空白 |

### 三条硬规则

1. 静默态下，**除回车外的任何按键 → 无反应**。
2. 静默态下，**左键点搜索框以外区域 → 无反应**。
3. **只有右键空白才能进捷径坞**。

> 页面上**没有**底部语句、没有便笺/待办 —— 保持绝对干净。

| --- | --- |

## 三、App 图标规范（重点）

**"图标即卡片"**：不要"白色卡片 + 中间一个小图标"（那看起来像网页书签），要像手机桌面。

| 项 | 规范 |
| --- | --- |
| 卡片尺寸 | 76×76，圆角 **19**（≈25%，接近 iOS 22.5%） |
| 图标尺寸 | **46×46（占卡片 60%）**，居中 |
| 底色 | 品牌主色（bilibili `#FB7299`、GitHub `#24292F`、微信读书 `#1AAD19`） |
| 白色系品牌 | 豆包 / ChatGPT 用纯白底 + 深色 logo（`#fff` + `#0d0d0d`） |
| 高光 | `::after` 顶部 160deg 白色渐变（透明度 .28→0），模拟玻璃光泽 |
| 阴影 | `0 6px 18px rgba(0,0,0,.26)`，hover 加深到 `0 16px 30px /.36` |
| hover | `translateY(-6px) scale(1.03)`，220ms |
| 名称 | 卡片外，11.5px，白 94%，`text-shadow 0 1px 5px rgba(0,0,0,.55)` |
| 降级 | favicon 抓取失败 → 品牌色底 + 白色首字（同名 SVG text） |

> 正式实现：`https://{域名}/favicon.ico` 自动抓取并缓存为 dataURL；失败用首字底图。

## 三之二、编辑捷径弹窗（右键图标 / 点＋）

**右键图标不再弹菜单**，直接打开「编辑网站捷径」弹窗。

```
┌──────────────────────────────────┐
│ 编辑网站捷径                  ×  │  272 宽 / 白底 / 圆角 12
│ ┌──────────────────────────────┐ │
│ │ 🔗  网址                      │ │  34 高 / 圆角 6 / 边框 #e5e7eb
│ └──────────────────────────────┘ │  focus：绿边框 + 2px 光晕
│ ┌──────────────────────────────┐ │
│ │ H   标题 - 留空即自动获取      │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 🖼  图标            指定 URL › │ │  浅灰底 #f5f5f5，右侧引导文字
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 📁  收纳夹              无  › │ │
│ └──────────────────────────────┘ │
│  删除        ┌────────────────┐   │
│              │      保存       │   │  亮绿渐变 / flex:1 / 34 高
└──────────────────────────────────┘
```

| 项 | 规范 |
| --- | --- |
| 触发 | 右键图标 → 编辑；点「＋」卡片 → 添加（标题变"添加网站捷径"，删除按钮隐藏） |
| 尺寸 | 272 宽，padding 14/16，白底 `#fff`，圆角 12，阴影 `0 22px 60px /.34` |
| 输入框 | 34 高，圆角 6，1px `#e5e7eb`，左置 14px 图标，字号 12；focus → 绿边框 + `0 0 0 2px rgba(13,148,136,.12)` |
| 行按钮 | 34 高，`#f5f5f5` 底，圆角 6，右侧灰色引导（`指定 URL ›` / `无 ›`） |
| 保存 | 亮绿渐变（`#8CC63F→#6DA02F`），白字 12.5px，`flex:1` |
| 删除 | 左侧纯文字按钮，`#dc2626`，hover 淡红底；新增模式下 `display:none` |
| 校验 | 网址为空 → 输入框聚焦 + 红色 Toast，不关闭弹窗 |
| 关闭 | × / 点遮罩 / Esc |
| 保存后 | 就地更新该项（名称、title），**不重渲染整组**，避免闪烁 |

## 三之三、拖拽排序

| 项 | 规范 |
| --- | --- |
| 开启 | 每个捷径卡 `draggable="true"`（「＋」卡不可拖） |
| 拖动中 | `opacity:.45` + `scale(.94)` + 加强阴影，`cursor:grabbing` |
| 落位 | `dragover` 时按**光标与最近卡片中心点的距离**决定插在其前/后，实时 `insertBefore` |
| 松手 | 只重写 `data-index` 与数据数组，**不重建 DOM**（无闪烁） |
| 与点击冲突 | 拖拽后 120ms 内的 click 忽略 |
| 持久化 | 顺序写入 storage，刷新后保持 |

## 三之四、性能约定（必须遵守）

| 项 | 上限 |
| --- | --- |
| `backdrop-filter` blur | **≤ 18px**（原 26-30px 在低配机明显掉帧） |
| 状态切换动画 | **250-300ms**（原 450-550ms 显得"慢半拍"） |
| 面板/浮层入场 | 150-200ms |
| 禁止 | `transition: all`、给大面积元素做 `filter`/`box-shadow` 动画 |
| DOM | 状态切换不重建列表；编辑保存就地更新 |
| 焦点 | 用 `requestAnimationFrame` 而非 `setTimeout` |

## 四、玻璃与配色

| 用途 | 配方 |
| --- | --- |
| 静默搜索框 | `linear-gradient(180deg,rgba(255,255,255,.30),rgba(255,255,255,.18))` + `blur(22px)` + 1px `rgba(255,255,255,.28)` |
| 深色浮层（历史/引擎） | `rgba(28,38,48,.80)` + `blur(26px) saturate(1.3)` |
| 追加卡片 | `rgba(255,255,255,.20)` + `blur(10px)` |

| Token | 值 | 用途 |
| --- | --- | --- |
| `--accent` | `#6DA02F` | 放大镜按钮、开关 |
| `--accent-light` | `#8CC63F` | 按钮渐变起点 |
| `--danger` | `#DC2626` | 删除 |

- 遮罩：静默 `.18` → 坞态 `.42`（设置可加深 `.55`）
- 噪点颗粒：`opacity .14` + `mix-blend-mode: overlay`
- 顶部暗角 `rgba(0,0,0,.5)→透明 26%`，保证时钟与顶栏可读

## 七、验收清单

1. 打开 → 时钟走字，只有一个「搜索」胶囊
2. 按 `a`/空格 → **无反应**；按**回车** → 进搜索态
3. 静默态点空白 → 无反应；点搜索框 → 进搜索态
4. 引擎徽标 → 6 引擎 + 偏好入口
5. 输入关键词 → 历史实时过滤；回车提交；Esc 返回
6. **右键空白** → 捷径坞（9 列，图标像手机 App）
7. **拖动窗口改宽度** → 列数自动增减，不溢出、不堆叠错位
8. 坞内**右键图标** → 打开「编辑网站捷径」弹窗（可改网址/标题、可删除、可保存）
9. 点「＋」→ 打开「添加网站捷径」弹窗，保存后新卡片出现
10. **拖动图标**可排序，松手后顺序固定、不闪烁
11. 设置面板：点齿轮打开，点空白/按 Esc/再点齿轮都能关闭（**不能关不掉**）
12. 页面**没有**底部语句、没有便笺待办、右上角**没有**笑脸图标
13. 操作手感：切状态、开弹窗、拖拽都跟手（≤300ms），无明显卡顿
14. 搜索框为**纯白胶囊**：左侧灰色引擎图标、右侧**绿色放大镜**（无底色圆），不抢眼
15. 壁纸支持**上传本地图片**（`<input type=file>` → FileReader → 设为背景），也可粘贴 URL
16. 捷径坞内点**卡片之间的空白**能退回静默态（不再"点哪都退不出"）
17. 拖动图标时其余卡片**平滑让位**（FLIP 190ms），无闪动、无跳位
