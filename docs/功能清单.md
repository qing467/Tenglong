## 四、性能优化记录（本轮）

| 项 | 优化前 | 优化后 |
| --- | --- | --- |
| 捷径坞事件 | 每张卡绑 4 个监听器（20 张 = 80 个） | **事件委托**，容器上只绑 4 个，重建卡片不再产生监听器 |
| 编辑保存 | 全量 `renderDock()` 重建 20 张卡 | **`patchItem(i)` 就地更新**单张卡 |
| 入场动画 | 重建后 20 张卡重新播放 rise（闪烁） | 动画改由 `.dock.enter` 控制，仅在**进入捷径坞**时播放 |
| 时钟 | `setInterval(1000)` 累积漂移，每秒写 DOM | 对齐秒边界 `1000 - Date.now()%1000`，**文本未变不写 DOM** |
| 历史下拉 | 每次 input 都重建 DOM | 计算 `key`，列表未变**不重建** |
| 偏好写入 | 每次点击立即写 localStorage | **防抖 150ms** 合并写入 |
| Toast | 无上限，可堆叠十几条 | 最多 **3 条**，超出移除最旧 |
| 状态切换 | 相同状态仍触发全量渲染 | 相同状态**直接 return** |
| CSS | `transition: all` | 改为具体属性（`transform` / `background` / `border-color`） |
| 拖拽 | 频繁重排 | `requestAnimationFrame` 节流 + 位置未变跳过 + 拖拽期 `will-change` |
| 模糊层数 | toast blur 20px | 降到 12px |

## 五、本轮修复的 Bug

1. **拖拽后右键编辑错项** —— 事件闭包捕获了创建时的索引；改为每次事件读取 `dataset.i`。
2. **`Alt+N` 写成 `ctrlKey`** —— 改为 `altKey`。
3. **新增捷径首字不可见** —— 白底卡片 + 白色文字；`T()` 增加颜色参数，新增项用深灰字。
4. **编辑弹窗固定居中** —— 改为跟随触发图标定位，并做视口边界收敛。
5. **设置无法退出** —— 补全「点空白 / Esc / 再点齿轮」三条关闭路径。
6. **点击图标附近无法退出捷径坞** —— 判定从 `#dock` 容器改为 `.dock-item`。
7. **壁纸切换后浮层配色割裂** —— 纯白壁纸下历史下拉、引擎弹层、设置抽屉全部转浅色。
8. **时钟在深色自定义壁纸上发虚** —— 选过纯白壁纸后浅色模式残留，时钟变深灰；改为**恒为白字** + 局部暗角，且应用自定义图片时自动退出浅色模式。
9. **内置精美图标被低清 favicon 覆盖** —— 内置 20 项标记 `brand:true`，改网址时不抓取 favicon，保住手工图标。
10. **上下暗角 + 打开捷径坞的灰层** —— `#scrim::after` 是一条上下黑渐变（顶部 .5 / 底部 .22），`body.state-dock #scrim` 又把整屏压到 .42；两者已删除，`#grain` 噪点层也已关闭。现在除黑暗模式外**没有任何覆盖层**，纯白即 `#FFFFFF`。
11. **壁纸选择刷新后回退** —— 壁纸未持久化，刷新会回到默认渐变（看起来像"四边阴影"）；现已随偏好保存，刷新保持。
12. **新增站点拖不动** —— 新站点卡片里有 `<img class="logo">`（favicon），而 `<img>` 默认可拖，按住图标拖的是图片本身而不是卡片，`dragstart` 拿不到 `.dock-item`。修复：`.tile img.logo{pointer-events:none;-webkit-user-drag:none}` + `<img draggable="false">`。内置站点的纯 SVG 图标没有这个问题，所以只有新加的站点拖不动。

### 6.2 修复的冲突与 Bug

1. **捷径坞溢出看不见** —— `html,body{overflow:hidden}`，站点变多后底部卡片永远滚不到；现给 `.dock` 加 `max-height` + 内部滚动（细滚动条，浅色壁纸下自动转深色）。
2. **`Esc` 关不了下拉** —— 输入框内 Esc 直接退出搜索态；现统一优先级：**弹窗 → 设置 → 下拉/弹层 → 退出状态**。
3. **搜索后下拉不刷新** —— `doSearch()` 未重建列表，新历史项要等下次输入才出现；现已补 `renderHist()`。
4. **自动清除后下拉残留旧数据** —— 清完历史没重置 `histKey`，补上。
5. **启动即回写存储** —— `loadPref()` 里 `setHour/setDark` 会触发 `savePref`，造成"读取→写入"回环；加 `silent` 参数。
6. **图片壁纸文字看不清** —— 自定义图片一律按深色处理；现**取样平均亮度**（16×16 缩略图），浅图自动转浅色模式（跨域图取样失败则按深色，不报错）。
7. **`inline onerror`** —— 真实扩展有 CSP 限制，内联事件会被拦；改为容器**捕获阶段**监听 `error`（`error` 不冒泡，必须用捕获）。
8. **窗口 resize 后弹窗跑出屏幕** —— 记住锚点，resize 时重新定位。
9. **拖到窗口外松手** —— `dragend` 有可能不触发，状态残留；补 `drop` 兜底清理。
10. **黑暗模式下壁纸圆点选中环色差** —— 内环固定 `#151a21`，与深色抽屉 `#12161c` 不一致；补 `body.dark` 覆盖。
11. **CSS 重复定义** —— `lightbg .note` 定义了两次；删除冗余一条。
12. **无用层** —— `#grain` 噪点层已关闭却仍在渲染；元素与样式一并删除。

### 6.3 流畅性

| 项 | 优化 |
| --- | --- |
| 拖拽 | `dragstart` 时**缓存全部卡片坐标**，只有真正换位后才重测；不再每帧对 20+ 张卡 `getBoundingClientRect`（每次都会触发重排）。容器滚动时重新测量 |
| 时钟 | 标签页回到前台**立即校正**（后台定时器会被节流到分钟级） |

| 图片 | favicon 加 `loading="lazy" decoding="async"`，不阻塞首屏 |

| 3 | 新增站点抓不到图标 | 只试站点 `/favicon.ico`，兜底源（Google s2 / iowen / favicon.im）在国内网络全不可达（实测 DNS / TLS / 超时） | 改为同源 5 条约定路径优先，外部服务只作兜底；新增 `Favicon.tsx` 多源降级；编辑弹窗加「图标地址」手填兜底 |
| 4 | 新增站点点击不跳转 | 拖拽尾巴保护用布尔标记，拖完若浏览器没补发 click，标记留到下一次点击把它吞掉 | 改 300ms 时间戳判定 |
| 5 | 壁纸像蒙层灰、亮度低 | `body.dark .wallpaper { filter: brightness(0.52) }` | 预设 0.82；自定义图片 `filter: none`（完全保留原亮度） |
| 6 | 搜索框暗淡、磨砂不足 | 静默胶囊 `rgba(255,255,255,.17)` + `blur(10px)` | 提到 `.3` + `blur(22px) saturate(1.8)`，加内高光 / 描边；浅色壁纸改白色磨砂卡片 |

**网络实测结论（决定方案的关键）**：`favicon.im` DNS 解析失败、`api.iowen.cn` TLS 握手失败、`favicon.yandex.net` 404、`google.com/s2/favicons` 超时、`statics.dnspod.cn` 返回 JSON、`favicon.cccyun.cc` 403 —— 因此图标不能指望外部服务，必须先吃站点自身资源。
