# 腾龙起始页

一个**纯本地、断网可用**的极简浏览器起始页扩展（Chrome / Edge，Manifest V3）。
无服务器、无账号、无数据上传，所有内容存在本机 `chrome.storage.local`。

> 项目进度：**v1.0.1 已交付** —— SOP 阶段 1~7 走完（M1~M7 + 阶段 6 验收打磨 + 阶段 7 打包交付），v1.0.1 修掉 6 个实测 bug（壁纸存不上、顶栏看不见、图标抓不到、点击被吞、壁纸发暗、搜索框偏灰）。
> 可直接安装：`nanotab/nanotab-v1.0.2.zip` 解压后用「加载已解压的扩展程序」选该目录，或选开发目录 `nanotab/dist`。
> 功能：壁纸 + 大号时钟 + 磨砂搜索框 / 右键进捷径坞（23 内置站点、收纳夹、拖拽排序）/ 右上角设置（壁纸、主题、时钟、历史、引擎管理、备份）。
> 未做（明确不做）：便笺待办（M5）；可选未做：`chrome.commands` 全局快捷键。

## 一、怎么装到浏览器（30 秒版）

1. 解压 `nanotab/nanotab-v1.0.2.zip` 到一个**不要删的固定目录**
2. `chrome://extensions` → 右上角开「开发者模式」→ 左上角「加载已解压的扩展程序」→ 选该目录
3. 新建标签页

### 数据存哪、会不会丢

全部存在 **`chrome.storage.local`**，写在磁盘的用户数据目录里：

```
<Chrome 用户数据目录>\Default\Local Extension Settings\<扩展 ID>\
```

| 场景 | 数据 |
| --- | --- |
| 关闭浏览器 / 重启电脑 | ✅ 保留 |
| 升级扩展版本 | ✅ 保留（含自动迁移） |
| 关掉再开新标签页 | ✅ 保留 |
| **卸载扩展** | ❌ 清除 |
| **清除浏览数据时勾选「扩展程序数据」** | ❌ 清除 |
| 无痕窗口使用 | ⚠️ 无痕窗口关闭后清除（独立一份） |
| 换一台电脑 | ❌ 不同步（`storage.local` 不跨设备） |

配额 10MB，本扩展实际占用几十 KB。防误清的**导出 / 导入备份**在 M7 设置面板里做。

## 六、目录结构

```
nanotab/
├─ public/
│  ├─ manifest.json          扩展清单（构建原样复制到 dist）
│  └─ icons/icon{16,32,48,128}.png  扩展图标
├─ newtab.html               新标签页入口
├─ popup.html                扩展图标弹窗入口
├─ src/
│  ├─ newtab/main.tsx        新标签页逻辑
│  ├─ popup/main.tsx         弹窗逻辑
│  ├─ lib/                   storage / engines / sites / favicon / dockPath / navigate / wallpapers
│  ├─ hooks/useAppData.ts    数据读写 + 防抖 + 跨标签页同步
│  └─ styles/global.css      全部样式
└─ dist/                     构建产物（浏览器加载的就是它）
```

> 没有 `src/background/`：本扩展无后台逻辑，manifest 也就不声明 service worker（少一个常驻进程）。

## 七、开发注意（踩坑点）

- **Vite 已关闭文件 hash**：`manifest.json` 写死 `newtab.js`/`popup.js`/`global.js`，不要开启 hash，否则扩展加载失败。
- **MV3 禁止内联脚本与 eval**：所有 JS 必须打包成本地外链文件。
- **禁止使用 `alert`/`confirm`**：扩展环境可能失效，统一用页面内 Toast。
- **壁纸必须压缩后再存**：原图转 dataURL 会写爆配额（默认 5MB），上传流程统一压到 2560px / 约 800KB，见 `lib/wallpapers.ts` 的 `compressImage`。
- **图标改动后要重新构建**：图标放在 `public/icons`，`npm run build` 才复制进 `dist`。

**已知限制**

- 数据不跨设备：`chrome.storage.local` 是本机存储，换电脑请走导出/导入
- 关闭/卸载扩展或勾选「清除扩展程序数据」会清空，靠导出 JSON 兜底
- 跨域图片壁纸无法采样亮度，一律按深色底处理（文字保持白色）
- 捷径坞最多两层（夹在坞上、站点在夹里），不支持夹中夹
- 图标是四层外部源依次降级（站点自身 → favicon.im → iowen → Yandex/Google），全部不可达时显示首字

**变更记录**

`v1.0.1`（本轮修复）

1. **大图壁纸存不上** —— 原来直接把原图转 dataURL，手机照片 5~10MB 直接写爆 `chrome.storage.local`（默认 5MB），写入静默失败，表现就是"换了壁纸，刷新又回退"。现在上传时统一压缩到最长边 2560 的 JPEG（约 200~800KB），并申请 `unlimitedStorage`；写盘彻底失败会弹 Toast 而不是无声无息。
2. **非捷径坞看不到设置 / 黑夜按钮** —— `.topbar` 以前是 `opacity: 0.38`，深色壁纸上几乎看不见。现在常驻不透明，按钮改成玻璃底 + 描边，浅色壁纸自动转深色图标。
3. **新站点抓不到图标** —— favicon 从"只有站点自身 `/favicon.ico` + 一个国内不可达的 Google 源"改成五级降级链，新增 `Favicon` 组件统一在卡片 / 收纳夹缩略图 / 收纳夹浮层三处使用。
4. **新站点点了不跳转** —— 拖拽尾巴保护原来是布尔标记：拖完若没补发 click，标记会留到下一次点击，把真正要打开的那次点击吞掉。改成 300ms 时间戳判定。
5. **壁纸像蒙了层灰** —— 黑暗模式对壁纸做 `brightness(0.52)`，压得发暗。改成预设 0.82、自定义图片 0.92，保留原图亮度。
6. **搜索框发暗、磨砂不足** —— 静默胶囊背景从 `rgba(255,255,255,.17)` 提到 `.3`，模糊 10px → 22px、saturate 1.8，加内高光与描边；浅色壁纸下从极淡的黑改成白色磨砂卡片。

`v1.0.0`（首个可交付版本）

- P0 全部完成：时钟、搜索与历史、捷径坞、壁纸与主题、设置与备份、扩展弹窗
- P1：自定义搜索引擎管理、收纳夹分组
- 修复：拖拽闪烁、点击不跳转（改用 `chrome.tabs.update`）、快捷坞网址丢失自愈、favicon 国内可达性
